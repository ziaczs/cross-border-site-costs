## 独立站本身要花多少钱

把一个能正常收单的跨境独立站跑起来，低成本路线一年 5000–10000 元，走定制开发则要 2 万元起步，功能复杂的综合商城会明显更高。

对没有技术团队的人来说，省事的路径是 Shopify 这类 SaaS 建站：基础套餐每月 29 美元起，一年约 348 美元（2400 元上下），再往上有每月 79 美元和 299 美元两档，差别除了功能，主要是平台佣金从 2% 递减到 0.5%。模板先用免费版，前期这块支出可以是 0；页面设计外包出去，几十到上百美元能做一套基础页面。

WordPress 自建站系统本身免费，但要自己买服务器，主题模板 350–700 元一套，功能插件每个 20–50 美元，还需要有人懂维护。算总账时别只看到“免费”两个字。

定制开发是另一条路：简单跨境独立站的定制报价在 3000–8000 美元（约 2 万–5.6 万元），复杂项目会到 2 万美元以上，开发周期 3–6 个月，之后每年还要预留开发成本的 20%–30% 做维护。刚试水就上定制开发，大概率是把钱花在了还没验证过的需求上。

顺便算一笔很多人忽略的账：Shopify 基础套餐和 79 美元套餐每月差 50 美元，佣金差 1%，月流水超过 5000 美元时升级反而更划算；而 299 美元档相对 79 美元档，月流水要到 44000 美元左右才回本。按流水选档位，比按“功能多少”选实在得多。

## 最容易漏掉的四笔钱

多数报价文章只列建站和网络，真正影响总账的往往是下面这几项：

1. **支付通道开户费**。PayPal 免费开通；想开 Stripe，有香港公司主体可以免开户费，个人通过服务商代办大约 3500–4000 元；用国内公司主体开 Asiabill 这类通道，开户费 5000–10000 元。这笔钱是一次性的，但不提前算，预算表第一天就爆。
2. **交易手续费和汇率差**。PayPal、Stripe 每笔约 2.9% + 0.3 美元；亚马逊每笔佣金 8%–15%；部分支付网关收 2%–4% 的交易费，再叠加外汇结算的汇率损耗。流水越大，这项越不能忽略。
3. **续费涨价**。域名首年常有折扣，续费普遍上浮 20%–30%；定制开发站每年的维护费是开发成本的 20%–30%。按首年价格做长期预算，第二年就对不上账了。
4. **内容与素材**。外包文案每千字 50–100 美元，一条产品视频 200–500 美元，图片素材每张几美元到几十美元。产品多的店，这项会持续滚动。

## 常见问题

**只在亚马逊开店、不做独立站，网络搭建要花多少钱？**
平台店没有建站投入，主要成本是专业卖家每月 39.99 美元的账户费加每笔 8%–15% 的销售佣金。但后台访问环境照样要解决，订阅型网络套餐就能覆盖，用不上专线。

**第一年最低能压到多少钱？**
5000 元上下：共享主机加 WordPress 免费主题，网络用最低档方案。但要留出广告预算——独立站没有自然流量，Facebook 代理账户开户免费，一般要求预存 1000 美元，这笔钱省不了。

**专线月租为什么从几千到几万差这么多？**
三个变量：两端物理距离、承诺的最低带宽、是否配置高可用方案。中国到欧美主流电商节点的中等带宽专线月租数千元起，带宽翻倍或加冗余链路，价格同步往上走。

**月流水多少该升级 Shopify 套餐？**
月流水超过 5000 美元升 79 美元档；299 美元档相当于从 79 美元档再往上，月流水到 44000 美元左右才划算。流水没到就留在基础套餐，省下的佣金补不回月费差价。
